# Python-Text-Adventure-Game

Your aunt leaves you to take care of her dog, Bella, while she's on vacation. When you arrive, you notice strange things happening around the house. Bella's food was recently recalled after accidentally containing growth hormones! Your goal is to find a way to return Bella to her normal size before your aunt comes home.

## Project Overview

This text-based adventure game was developed using Python as part of my IT-140 course at Southern New Hampshire University.

### Skills Demonstrated
- Python programming
- Conditional statements and loops
- Dictionaries and inventory management
- User input and game navigation
- Testing and debugging

### How to Run
1. Download `TextBasedGame.py`.
2. Open the file in a Python-compatible IDE or terminal.
3. Run the program using Python 3.
4. Follow the on-screen instructions to play.
